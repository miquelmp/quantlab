# Privacidad

**Resumen: esta web no recoge datos personales, no usa cookies y no tiene cuentas de usuario.**

## Lo que se guarda en tu navegador

Para que puedas seguir donde lo dejaste, la web guarda en tu propio navegador (almacenamiento local), y solo allí:

- las secciones que has leído, los ejercicios que has resuelto y los retos de los gráficos que has conseguido;
- la última sección visitada;
- tus preferencias de lectura (tema claro u oscuro, tamaño de letra, Ampliación abierta o cerrada).

Estos datos nunca salen de tu dispositivo. Puedes borrarlos cuando quieras desde los ajustes de tu navegador (borrar los datos de este sitio). Si tu navegador no permite guardarlos, la web funciona igual, sin recordar el progreso.

## Python en tu navegador

El código Python se ejecuta dentro de tu navegador, aislado del resto de la página. El código que escribes no se envía a ningún servidor. La primera vez que pulsas «Ejecutar», el navegador descarga el intérprete de Python (Pyodide) desde la red de distribución jsDelivr, que, como cualquier servidor web, recibe la dirección IP necesaria para entregar los ficheros.

## Alojamiento

La web se aloja en GitHub Pages. GitHub puede registrar datos técnicos de las visitas (como la dirección IP) por motivos de seguridad, según su propia [declaración de privacidad](https://docs.github.com/es/site-policy/privacy-policies/github-general-privacy-statement).

## Analítica

Para saber qué páginas se leen más, la web usa [GoatCounter](https://www.goatcounter.com/), un servicio de analítica anónimo y sin cookies. Por cada página vista se envía la dirección de la página, la web de la que vienes (si la hay), el tamaño de la pantalla y el tipo de navegador. No se guarda tu dirección IP ni nada que permita identificarte o seguirte entre sitios. Puedes consultar su [política de privacidad](https://www.goatcounter.com/help/privacy). Si tu navegador bloquea la analítica, la web funciona igual.

## Avisos de errores

El enlace «Avisar de un error» abre un formulario en GitHub. Lo que escribas allí será público y quedará asociado a tu cuenta de GitHub.
