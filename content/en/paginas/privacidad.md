# Privacy

**Summary: this website does not collect personal data, does not use cookies and has no user accounts.**

## What is stored in your browser

So that you can pick up where you left off, the website stores in your own browser (local storage), and only there:

- the sections you have read, the exercises you have solved and the chart challenges you have completed;
- the last section visited;
- your reading preferences (light or dark theme, font size, Going further open or closed).

These data never leave your device. You can delete them whenever you like from your browser settings (clear the data for this site). If your browser does not allow storing them, the website works just the same, without remembering your progress.

## Python in your browser

Python code runs inside your browser, isolated from the rest of the page. The code you write is not sent to any server. The first time you press «Run», the browser downloads the Python interpreter (Pyodide) from the jsDelivr content delivery network, which, like any web server, receives the IP address needed to deliver the files.

## Hosting

The website is hosted on GitHub Pages. GitHub may log technical data about visits (such as the IP address) for security reasons, according to its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Analytics

To know which pages are read most, the website uses [GoatCounter](https://www.goatcounter.com/), an anonymous, cookie-free analytics service. For each page viewed it sends the page address, the website you came from (if any), the screen size and the browser type. Your IP address is not stored, nor anything that could identify you or track you across sites. You can read its [privacy policy](https://www.goatcounter.com/help/privacy). If your browser blocks analytics, the website works just the same.

## Error reports

The «Report an error» link opens a form on GitHub. What you write there will be public and associated with your GitHub account.
